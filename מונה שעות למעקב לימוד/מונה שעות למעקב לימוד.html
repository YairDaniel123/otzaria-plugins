כדי להפעיל סנכרון אמיתי, יש לבצע הגדרה חד-פעמית:
1. כנס ל-console.cloud.google.com
2. צור פרויקט חדש → הפעל את Google Drive API
3. APIs & Services → Credentials → OAuth 2.0 Client ID
4. סוג: Web application · הוסף את כתובת הקובץ כ-Authorized origin
5. העתק את ה-Client ID והדבק כאן:
הנתונים נשמרים ב-AppData folder — פרטיים לחלוטין, גלויים רק לאפליקציה זו.

  • השהה / המשך — עצור ותחדש בלי לאבד זמן

  • הפעלה אוטומטית — הגדר בהגדרות "הפעל טיימר אוטומטי בפתיחה"
יעדים יומיים
  • הגדר יעד שעות לכל יום בשבוע (א–ש) עם הסליידר
  • הוסף תאריכים מיוחדים — חגים, ערבי חג, ימי מנוחה (עם יעד 0)
  • חגים יהודיים 5785 נטענים אוטומטית בהתקנה ראשונה
  • תצוגת "שבוע נוכחי" מציגה יעד vs. ביצוע לכל יום
נושאים
  • צור נושאי לימוד עם שם, צבע ויעד יומי (גמרא, הלכה, מוסר...)
  • הגדר תקופת פעילות לנושא (תמיד / טווח תאריכים)
  • הגדר טווחי שעות (סדרים) — למשל "סדר בוקר" 08:00–13:30 ותראה מילוי אחוזי
  • ניתן לבחור מספר נושאים לאותו סשן בטיימר (chips)
הוספה ידנית
  • הוסף שעות שלא נרשמו בזמן אמת — תאריך, שעת התחלה/סיום, נושא
  • ניתן להוריד דקות הפסקה אוטומטית
  • תאריך עברי מוצג מיד בעת בחירת תאריך

  • היסטוריה — חיפוש, סינון לפי תאריך, מחיקת רשומות
